>

自用。純靜態、零依賴、可離線；進度存在瀏覽器本機。

## 怎麼開

- **直接開**：雙擊 `index.html`（file:// 即可，本站不做任何 fetch）。
- **要好用一點**（手機加入主畫面、避免部分瀏覽器對 file:// 的 localStorage 限制）：

```bash
cd shanghan-reader && python3 -m http.server 8765
# 開 http://127.0.0.1:8765
```
手機同 Wi-Fi 時用電腦的內網 IP 即可。

## 三層劑量（方藥頁）

| 層 | 例（桂枝湯之桂枝） | 來源 |
|---|---|---|
| ① 原文組成 | 桂枝三兩 | 底本 |
| ② 漢制換算 | ≈ 46.9g | 底本附錄一（漢制實測，1 兩 ≈ 15.625g） |
| ③ 今日常用量 | 3–10g | 《中國藥典》2020／中藥學教材 |

> **③ 大致落在「明清折算」（1 兩 ≈ 3g）附近，而不是 ①。**
> 這是讀古方最容易誤解的一點：附錄一的 46.9g 是「漢代實際用量」，不是「今天的處方用量」。
>
> ⚠ ③ **不是《傷寒雜病論》的內容**，provenance 標為 `modern_reference`，與原文嚴格分離，
> 僅供讀書理解，**不構成處方依據**。

## ⚠ 起點不是卷第一

「全書」頁從卷第一〈平脈法〉開始，那是**全書最抽象的一卷**。
初讀請先走「🧱 準備」→「記誦」六經提綱 → 再從**卷六〈太陽病上〉**進入全書；
〈平脈法〉留到有具體經驗之後再讀。**編次順序 ≠ 學習順序。**

## 知識圖譜（🕸 圖譜頁）

四個維度全部有條文依據：

- **發展**：外感＝六經傳變【3.12–3.23】（雙時間軸：1–7 日受病／7–12 日病衰）；
  內傷＝四組結構（咳嗽臟腑相移 6 條、水氣五類、虛勞由勞至乾血、化癰趨勢）
- **截斷**：10 條通則，含【6.8】「**使經不傳則愈**」；分「加」與「不加」兩種形態
- **誤診**：誤認→誤治→變證→更正，8 條核心，**每條掛上「用哪一診能認對」**
- **治癒**：汗出而解 29／欲解 20／自愈 13／死難治 40

> 誤診鏈的統計值得單獨一課：**八條之中七條只要問診就能避免**——
> 誤診的代價通常不是「不會治」，是「沒問清楚」。

模型說明見 `../docs/09-知識圖譜模型.md`；資料在 `assets/data.js` 的 `SH.kg`。

## 五步讀書法

每讀一條，固定問五個問題（見「理念」頁）：

```
① 認位 → 卷・篇・條號
② 辨體 → 問曰／師曰／方後注／可與不可
③ 識力 → 模態詞（主之／宜／可與／不可）＝ 證據強度
④ 通方 → 方名・組成・劑量
⑤ 存疑 → 異文・對齊信心
```

原文中的**黃色標記**就是第③步要你注意的證據強度詞。
刻意**不標**「當」「為」「愈」這類常用虛詞——全標等於沒標。

## ⚠ 已知限制（「關於 → 出處與信心」頁有完整說明）

1. **條號↔條文綁定部分未定**：約三成條文為 `provisional`（其所在卷的區塊數與條號數不符）。
   可讀、可統計，但**引用條號前須回查原文**。
2. **頁碼驗證只及於含方之條**：以底本〈湯方索引〉頁碼獨立驗證方→條綁定，吻合 95.2%；
   但不含方的條文（多為脈法、禁忌、預後）無從施力。
3. **繁簡回轉污染**：底本係簡→繁一鍵轉換產物（複→復、髒→臟、餘→余、雲→云、曆→歷、
   幹→干、鬥→斗），另發現一類新誤轉 **湯→東**（如「大青龍**東**加附子湯」）。
   本站原文**保留原樣**，以存版本資訊——這是讀書訓練的一部分，不是要修掉的錯字。
4. **「讀到這裡要停下來」三類**：校勘異文 116、方頭與條文所稱不一致 14、繁簡污染。

## 紅線（課孫時守住）

1. 不教相術（面相、手相、骨相）。
2. 不作人身判讀——讀醫書是**病理求真**，不是評價人。
3. **預後 ≠ 命定**：平脈法的「生／死／難治」是診治斷言（說「難治」是為了換思路，
   說「死」是為了及早轉手），與《冰鑑》那類「以貌定貴賤」是兩回事。
   教學時要把**觀察層**（如蟹腹＝潤澤、如枳實＝枯暗）與**判斷層**分開講。
4. 不做臨床應用。本站是讀書訓練，不是診療工具。
